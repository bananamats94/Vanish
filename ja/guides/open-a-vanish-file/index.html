.vanish ファイルを開く

無料

.vanish ファイルは、暗号化された受け渡し用のファイルです。iPhoneまたはiPadのVanishアプリで開きます。無料で、アカウントは不要です。

手順

  1. Vanishをまだ持っていなければ、App Storeから入手します。
  2. 「メッセージ」、メール、WhatsApp、「ファイル」アプリ、またはAirDropで受け取った .vanish ファイルをタップします。Vanishで開きます。
  3. Vanishに封をした受け取りと表示されます。見るをタップします。
  4. ファイルがコードで保護されている場合は、コードを入力に入力します。コードは、送り主から直接伝えられたり電話で聞いたりと、別の方法で受け取ります。
  5. 内容が開きます。下部に受け取った日時が表示され、あと何回見られるかもVanishが示します（例：「一度だけ表示できます。」）。

知っておくこと

  • 受け取りは常に無料です。送り主がPro機能の条件を選んでいても同じです。
  • iPhoneやiPadがないと、.vanish ファイルは開けません。ブラウザ版はありません。
  • 「この受け渡しは期限切れです。」は、送り主が決めた期限が過ぎたという意味です。もう一度送ってもらってください。
  • 「コードが正しくありません。」と出たら、4文字ずつのまとまりを確認し、不明なら送り主に尋ねてください。
  • 受け渡しが場所に紐づいている場合、Vanishには位置情報「常に」の許可が必要です。許可がないと開けません。
  • 転送、書き出し、コピーは、送り主が許可していない限りできません。
