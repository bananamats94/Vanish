身分証のコピーを安全に送る

Pro

不動産会社、銀行、新しい勤務先。身分証のコピーを送る場面は多いものの、チャットにずっと残したくはありません。Vanishは両面をスキャンし、用途の注記を入れ、有効期限つきでコピーを送ります。

手順

  1. カメラ下部でモード書類を選び、シャッターを押します。
  2. 何をスキャンしますか?で身分証をタップします。表面、裏面の順にスキャンします。
  3. 用途の注記に、コピーの用途を入力します（例：「賃貸の入居申込にのみ使用するコピー」）。注記はページに固定されます。
  4. PDF として保存をタップします。両面が1ページのPDFにまとまります。
  5. 今すぐ封印して送りますか?と聞かれたら、封印して送るをタップします。
  6. 条件を設定します。期限は開封期限、開ける回数は表示回数です。コードで保護するは最初からオンです。
  7. ファイルを作成をタップし、好きな方法でファイルを送ります。コードが表示されるのはこのときだけです。コードは別の方法で、できれば直接伝えてください。

知っておくこと

  • 身分証のスキャンはProです。24時間を超える期限や、2回以上の表示にもProが必要です。
  • 受け取る人には、iPhoneまたはiPadのVanishが必要です。受け取りは無料です。
  • コードが守るのは送る経路であり、受け取る人のスマートフォンではありません。別のスマートフォンで画面を撮影されるのは、どのアプリにも防げません。
  • 送る前に黒塗りで、アクセス番号など誰も必要としない欄を隠せます。
