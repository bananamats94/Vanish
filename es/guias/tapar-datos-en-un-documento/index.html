Tapar el IBAN y la dirección en un documento

Gratis

Antes de enviar una liquidación o un contrato, no todo lo que contiene debería poder leerse. Vanish encuentra IBAN, identificadores fiscales, direcciones y más, y graba las barras de forma permanente.

Cómo funciona

  1. Abre la bóveda, pulsa la foto o el PDF, después «…» arriba a la derecha y Tapar.
  2. Vanish lee el texto en el dispositivo y marca sugerencias en naranja, como un IBAN, un identificador fiscal, un teléfono, una dirección o un número de documento.
  3. Pulsa una sugerencia para quitarla. Tus propias zonas las tapas pulsando una palabra, con doble toque en una línea o arrastrando sobre una superficie.
  4. Con Deshacer quitas la última barra y con Todas las sugerencias aceptas todas las zonas naranjas.
  5. Pulsa Guardar y elige Guardar como versión nueva. El original se queda entonces en la bóveda.

Conviene saber

  • Tapar es gratis y funciona con fotos y PDF.
  • Las barras se integran en la imagen o la página. Debajo no queda texto que se pueda seleccionar.
  • Las sugerencias son una ayuda, no una garantía. Revisa el resultado antes de enviar.
  • Reemplazar el original borra la versión sin tapar. No se puede deshacer.
