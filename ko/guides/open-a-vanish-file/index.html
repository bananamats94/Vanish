.vanish 파일 열기

무료

.vanish 파일은 암호화된 전달 파일입니다. iPhone이나 iPad의 Vanish 앱으로 엽니다. 무료이며 계정이 필요 없습니다.

진행 방법

  1. Vanish가 아직 없다면 App Store에서 받으세요.
  2. 메시지, 메일, WhatsApp, 파일 앱에서, 또는 AirDrop으로 받은 .vanish 파일을 누르세요. Vanish에서 열립니다.
  3. Vanish에 봉인된 전달이 표시됩니다. 보기를 누르세요.
  4. 파일이 코드로 보호되어 있다면 코드 입력에 코드를 입력하세요. 코드는 보낸 사람이 직접 알려 주거나 전화로 알려 주는 등, 다른 경로로 전달합니다.
  5. 내용이 열립니다. 아래에는 받은 시각이 표시되고, 앞으로 몇 번 더 볼 수 있는지도 Vanish가 알려 줍니다(예: ‘한 번만 볼 수 있습니다.’).

알아 두세요

  • 받는 것은 언제나 무료입니다. 보낸 사람이 Pro 조건을 골랐어도 마찬가지입니다.
  • iPhone이나 iPad가 없으면 .vanish 파일을 열 수 없습니다. 브라우저 버전은 없습니다.
  • ‘이 전달은 만료되었습니다.’는 보낸 사람이 정한 기한이 지났다는 뜻입니다. 다시 보내 달라고 요청하세요.
  • ‘코드가 올바르지 않습니다.’가 나오면 네 글자씩 끊은 묶음을 확인하고, 잘 모르겠으면 보낸 사람에게 물어보세요.
  • 전달에 장소 조건이 있으면 Vanish에 위치 접근 ‘항상’ 허용이 필요합니다. 그렇지 않으면 열리지 않습니다.
  • 전달, 내보내기, 복사는 보낸 사람이 허용하지 않는 한 막혀 있습니다.
