신분증 사본을 안전하게 보내기

Pro

집주인, 은행, 새 직장. 신분증 사본을 보내야 할 때가 많지만 채팅에 계속 남아 있는 것은 원하지 않습니다. Vanish는 양면을 스캔하고 용도 표시를 넣은 뒤, 만료 시간과 함께 사본을 보냅니다.

진행 방법

  1. 카메라 아래에서 문서 모드를 고르고 셔터를 누르세요.
  2. 무엇을 스캔하나요?에서 신분증을 누르세요. 앞면을 먼저, 그다음 뒷면을 스캔합니다.
  3. 용도 표시에 사본의 용도를 적으세요(예: ‘임대 신청 전용 사본’). 표시는 페이지에 고정됩니다.
  4. PDF로 저장을 누르세요. 양면이 PDF 한 페이지에 담깁니다.
  5. 지금 봉인해서 보낼까요?라고 물으면 봉인해서 보내기를 누르세요.
  6. 조건을 설정하세요. 기한은 열기 기한에서, 열 수 있는 횟수는 보기 횟수에서 정합니다. 코드로 보호하기는 이미 켜져 있습니다.
  7. 파일 만들기를 누르고 원하는 방법으로 파일을 보내세요. 코드는 지금 한 번만 표시됩니다. 코드는 다른 경로로, 가능하면 직접 말로 전달하세요.

알아 두세요

  • 신분증 스캔은 Pro 기능입니다. 24시간을 넘는 기한과 두 번 이상 보기에도 Pro가 필요합니다.
  • 받는 사람에게는 iPhone이나 iPad의 Vanish가 필요합니다. 받는 것은 무료입니다.
  • 코드는 보내는 경로를 보호할 뿐, 받는 사람의 휴대폰을 보호하지는 않습니다. 다른 휴대폰으로 화면을 촬영하는 것은 어떤 앱도 막을 수 없습니다.
  • 보내기 전에 가리기로 접속 번호처럼 아무도 필요하지 않은 칸을 가릴 수 있습니다.
