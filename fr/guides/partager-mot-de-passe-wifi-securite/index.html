Partager un mot de passe Wi-Fi ou des identifiants en toute sécurité

Gratuit

Un mot de passe Wi-Fi pour des invités ou des identifiants pour ta sœur doivent arriver, mais sans rester pour toujours dans une discussion. Dans Vanish, tu les écris dans une note et tu l’envoies scellée.

Comment ça marche

  1. Dans l’appareil photo, choisis en bas le mode Note et appuie sur le déclencheur. Seul l’éditeur s’ouvre, rien n’est enregistré.
  2. Écris le mot de passe ou les identifiants.
  3. Dans Supprimer après, choisis combien de temps la note reste sur ton téléphone.
  4. Touche Enregistrer et sceller.
  5. Laisse Vues sur 1, règle un délai dans Ouvrir avant et touche Créer le fichier. Transmets le code par un autre moyen.

Bon à savoir

  • Créer et sceller des notes est gratuit. Les durées de plus de 24 heures et plus d’une vue demandent Pro.
  • Avec Pro, tu peux faire supprimer la remise quand le destinataire quitte un lieu. « Ouvrir uniquement à un endroit » n’existe pas.
  • Dans le coffre, une note n’affiche qu’un cadenas, pas son contenu.
