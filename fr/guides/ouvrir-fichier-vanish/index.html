Ouvrir un fichier .vanish

Gratuit

Un fichier .vanish est une remise chiffrée. Tu l’ouvres avec l’app Vanish sur un iPhone ou un iPad. C’est gratuit et sans compte.

Comment ça marche

  1. Télécharge Vanish sur l’App Store si tu ne l’as pas encore.
  2. Touche le fichier .vanish dans Messages, Mail, WhatsApp, Fichiers ou après un AirDrop. Il s’ouvre dans Vanish.
  3. Vanish affiche Remise scellée. Touche Voir.
  4. Si le fichier est protégé par un code, saisis-le dans Saisir le code. La personne t’a donné le code par un autre moyen, par exemple de vive voix ou par téléphone.
  5. Le contenu s’ouvre. En bas, tu vois quand tu l’as reçu. Vanish indique combien de fois tu peux encore le consulter, par exemple « Visible une seule fois. »

Bon à savoir

  • Recevoir est toujours gratuit, même si la personne a choisi des conditions Pro.
  • Sans iPhone ni iPad, impossible d’ouvrir un fichier .vanish. Il n’existe pas de version pour navigateur.
  • « Cette remise a expiré. » signifie que le délai fixé par la personne est dépassé. Demande-lui de renvoyer le fichier.
  • « Le code n’est pas correct. » Vérifie les groupes de quatre caractères et, en cas de doute, demande à la personne.
  • Si la remise est liée à un lieu, Vanish a besoin de « Position : Toujours ». Sinon, il ne l’ouvre pas.
  • Le transfert, l’export et la copie sont bloqués, sauf si la personne les a autorisés.
