Envoyer une copie de ta pièce d’identité en toute sécurité

Pro

Propriétaire, banque, nouvel emploi : on te demande souvent une copie de ta pièce d’identité, mais elle ne doit pas rester pour toujours dans une discussion. Vanish scanne les deux faces, y inscrit une mention d’usage et envoie la copie avec une expiration.

Comment ça marche

  1. Dans l’appareil photo, choisis en bas le mode Document et appuie sur le déclencheur.
  2. À Que scannez-vous ?, touche Pièce d’identité. Scanne d’abord le recto, puis le verso.
  3. Dans Mention d’usage, indique à quoi sert la copie, par exemple « Copie uniquement pour le dossier de location Müller ». La mention est fixée sur la page.
  4. Touche Enregistrer en PDF. Les deux faces se retrouvent sur une seule page de PDF.
  5. À la question L’envoyer scellé maintenant ?, touche Envoyer scellé.
  6. Règle les conditions : le délai dans Ouvrir avant et le nombre d’ouvertures dans Vues. Protéger par un code est déjà activé.
  7. Touche Créer le fichier et envoie le fichier par le moyen de ton choix. Vanish n’affiche le code qu’à ce moment-là. Transmets-le par un autre moyen, idéalement de vive voix.

Bon à savoir

  • Le scan de pièce d’identité est Pro. Les délais de plus de 24 heures et plus d’une vue demandent aussi Pro.
  • Le destinataire a besoin de Vanish sur un iPhone ou un iPad. Recevoir est gratuit.
  • Le code protège le trajet, pas le téléphone du destinataire. Aucune app ne peut empêcher de photographier l’écran avec un deuxième téléphone.
  • Avec Masquer, tu peux d’abord couvrir les champs dont personne n’a besoin.
