Ausweiskopie sicher verschicken

Pro

Vermieterin, Bank, neuer Job: Oft soll eine Ausweiskopie raus, aber nicht für immer in einem Chat liegen. Vanish scannt beide Seiten, schreibt einen Zweckvermerk darauf und verschickt die Kopie mit Ablauf.

So geht’s

  1. Wähle in der Kamera unten den Modus Dokument und drück den Auslöser.
  2. Bei Was scannst du? tippst du Ausweis. Scanne erst die Vorderseite, dann die Rückseite.
  3. Trag bei Zweckvermerk ein, wofür die Kopie ist, etwa „Kopie nur für Wohnungsbewerbung Müller“. Der Vermerk steht fest auf der Seite.
  4. Tippe Als PDF speichern. Beide Seiten landen auf einer PDF-Seite.
  5. Auf die Frage Jetzt versiegelt senden? tippst du Versiegelt senden.
  6. Stell die Bedingungen ein: bei Öffnen bis die Frist, bei Ansichten wie oft sie sich öffnen lässt. Mit Code schützen ist schon an.
  7. Tippe Datei erzeugen und schick die Datei über einen beliebigen Weg. Den Code zeigt Vanish nur jetzt an. Gib ihn auf anderem Weg weiter, am besten mündlich.

Gut zu wissen

  • Der Ausweis-Scan ist Pro. Auch Fristen über 24 Stunden und mehr als eine Ansicht brauchen Pro.
  • Die Empfängerin braucht Vanish auf einem iPhone oder iPad. Empfangen ist kostenlos.
  • Der Code schützt den Weg, nicht das Handy der Empfängerin. Ein Foto vom Bildschirm mit einem zweiten Handy kann keine App verhindern.
  • Mit Schwärzen kannst du vorher Felder abdecken, die niemand braucht, etwa die Zugangsnummer.
