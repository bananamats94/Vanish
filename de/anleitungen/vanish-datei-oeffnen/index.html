Eine .vanish-Datei öffnen

Kostenlos

Eine .vanish-Datei ist eine verschlüsselte Übergabe. Du öffnest sie mit der App Vanish auf einem iPhone oder iPad. Das ist kostenlos und braucht kein Konto.

So geht’s

  1. Lade Vanish aus dem App Store, falls du es noch nicht hast.
  2. Tippe die .vanish-Datei in Nachrichten, Mail, WhatsApp, Dateien oder nach AirDrop an. Sie öffnet sich in Vanish.
  3. Vanish zeigt Versiegelt erhalten. Tippe Ansehen.
  4. Ist die Datei mit einem Code geschützt, gib ihn bei Code eingeben ein. Den Code hat dir die Person auf anderem Weg gegeben, etwa mündlich oder per Anruf.
  5. Der Inhalt öffnet sich. Unten steht, wann du ihn empfangen hast. Wie oft du ihn noch ansehen kannst, zeigt Vanish an, etwa „Nur einmal sichtbar.“

Gut zu wissen

  • Empfangen ist immer kostenlos, auch wenn die Person Pro-Bedingungen gewählt hat.
  • Ohne iPhone oder iPad lässt sich eine .vanish-Datei nicht öffnen. Eine Browser-Version gibt es nicht.
  • „Diese Übergabe ist abgelaufen.“ bedeutet: Die Frist der Person ist vorbei. Bitte sie, die Datei neu zu schicken.
  • „Der Code stimmt nicht.“ Prüfe die Vierergruppen und frag im Zweifel bei der Person nach.
  • Verlangt die Übergabe einen Ort, braucht Vanish „Standort: Immer“. Sonst öffnet es sie nicht.
  • Weitergeben, Exportieren und Kopieren sind gesperrt, außer die Person hat es erlaubt.
